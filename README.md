# 평범한 스파이 · 회색 안개 작전

합천중학교 마음돌봄 팝업 「평범한 스파이」 방탈출 웹앱 프로토타입입니다.
휴대폰 브라우저에서 바로 열리는 단일 페이지(`index.html`)이고, 서버 없이 진행 상황은 각 휴대폰에만 저장됩니다.

- `index.html`: 본체 (4주 구성, 학교 지도, 늘곰 본부 지령, 장소별 NPC와 미니게임, 수사보드, 라디오·마음 날씨·도움전화, 캐릭터 꾸미기, 교무실·교장실, 하늘 게시판, 몽글이 키우기, 주차별 말랑이)
- `spyplus.js`: 요원 계급, 안개 복도 잠입, 장비 도감, 비밀 코드, 전교 정화 작전
- `img/`: 늘곰 이미지

개인정보(이름·학번 등)는 수집하지 않습니다.
