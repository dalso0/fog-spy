# 평범한 스파이 · 회색 안개 작전

합천중학교 마음돌봄 팝업 「평범한 스파이」 방탈출 웹앱 프로토타입입니다.
휴대폰 브라우저에서 바로 열리는 단일 페이지(`index.html`)입니다. 진행 상황은 각 휴대폰에 저장되고, 본부 서버(구글 시트)에는 이름 없는 합계 숫자와 하늘 게시판 한 줄만 모입니다.

- `index.html`: 본체 (3주 구성 11.16~12.4, 학교 지도, 매일 저녁 3분 브리핑, 장소별 NPC와 미니게임, 수사보드, 라디오·마음 날씨·도움전화, 캐릭터 꾸미기, 교무실·교장실, 하늘 게시판, 요원 사물함과 말랑이)
- `spyplus.js`: 요원 계급, 안개 복도 잠입, 장비 도감, 비밀 코드, 전교 정화 작전
- `img/`: 늘곰 이미지

개인정보(이름·학번 등)는 수집하지 않습니다.

## 매일 들어오게 하는 구조

- **저녁 브리핑(3분):** 오늘 지령 보고 → 오늘 밤 조각 → 내일의 지령. 지령은 전날 저녁에 받아 다음 날 학교에서 폰 없이 하고, 그날 저녁에 보고합니다.
- **요일별:** 조각은 월·화·수 저녁에 하나씩 열리고(미리 열 수 없음, 밀린 조각은 몰아서 가능), 목요일 암호 해독, 금요일 주간 결산. 3주차 금요일은 최종 작전.
- **주차별 개방:** 1주차 운동장·미술실·진로실·본부·하늘 게시판 → 2주차 도서관·음악실·명상숲·교장실·안개 복도·장비 도감·라디오·교무실(출입금지 장난) → 3주차 급식실·보건실·교무실 원어민 선생님·비밀 코드.
- **쌓이기만 하는 보상:** 브리핑을 마친 날마다 지도 한 칸 색 회복(15칸), 사물함 물건 하나, 소장 비밀 파일 한 줄. 연속 기록이나 줄어드는 수치는 없습니다.
- **시연 모드:** 깃허브 Pages 주소가 아닌 곳(미리보기, 파일)에서는 로비에서 주차·요일을 고를 수 있고, 브리핑 끝에 「다음 날 저녁으로」 버튼이 있습니다.

## 실제 운영 (본부 서버)

- 학생 주소: `https://dalso0.github.io/fog-spy/` (GitHub Pages, main 브랜치)
- 선생님 관리실: `https://dalso0.github.io/fog-spy/admin.html` (관리 비밀번호는 구글 시트 '설정' 탭)
- `config.js`: 본부 서버(Apps Script 웹 앱) 주소 `window.HQ_URL`. 비어 있으면 서버 없이 동작
- `hq.js`: 학생 앱 ↔ 본부 연결. 하루 한 번만 세는 합계(+1)와 하늘 게시판 글만 보냄
- `server/Code.gs`, `server/appsscript.json`: 구글 시트에 붙이는 서버 코드. 탭: 설정 · 하늘게시판 · 통계 · 음악
- `admin.html`: 하늘 게시판 공개/숨김, 참여 숫자(주차별·날짜별, CSV), 첫 화면 공지

모이는 숫자(날짜별): 접속한 휴대폰 수, 브리핑 완료, 지령 보고(했다/비슷하게/못 했다), 조각, 암호 해독, 최종 작전, 마음 날씨, 도움전화 화면, 걱정되는 말 감지, 하늘 글, 라디오 좋아요, 정화 기여, 미니게임, 호흡실.
요원 코드·이름·기기 번호·IP는 보내지 않습니다. 걱정되는 말은 앱이 글을 보내지 않고 숫자만 +1 한 뒤 도움전화를 먼저 보여 줍니다.

서버 코드를 고친 뒤에는 Apps Script에서 **배포 → 배포 관리 → 수정 → 새 버전**으로 올려야 주소가 그대로 유지됩니다.
