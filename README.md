# 평범한 스파이 · 회색 안개 작전

합천중학교 마음돌봄 팝업 「평범한 스파이」 방탈출 웹앱 프로토타입입니다.
휴대폰 브라우저에서 바로 열리는 단일 페이지(`index.html`)이고, 서버 없이 진행 상황은 각 휴대폰에만 저장됩니다.

- `index.html`: 본체 (3주 구성 11.16~12.4, 학교 지도, 매일 저녁 3분 브리핑, 장소별 NPC와 미니게임, 수사보드, 라디오·마음 날씨·도움전화, 캐릭터 꾸미기, 교무실·교장실, 하늘 게시판, 요원 사물함과 말랑이)
- `spyplus.js`: 요원 계급, 안개 복도 잠입, 장비 도감, 비밀 코드, 전교 정화 작전
- `img/`: 늘곰 이미지

개인정보(이름·학번 등)는 수집하지 않습니다.

## 매일 들어오게 하는 구조

- **저녁 브리핑(3분):** 오늘 지령 보고 → 오늘 밤 조각 → 내일의 지령. 지령은 전날 저녁에 받아 다음 날 학교에서 폰 없이 하고, 그날 저녁에 보고합니다.
- **요일별:** 조각은 월·화·수 저녁에 하나씩 열리고(미리 열 수 없음, 밀린 조각은 몰아서 가능), 목요일 암호 해독, 금요일 주간 결산. 3주차 금요일은 최종 작전.
- **주차별 개방:** 1주차 운동장·미술실·진로실·본부·하늘 게시판 → 2주차 도서관·음악실·명상숲·교장실·안개 복도·장비 도감·라디오·교무실(출입금지 장난) → 3주차 급식실·보건실·교무실 원어민 선생님·비밀 코드.
- **쌓이기만 하는 보상:** 브리핑을 마친 날마다 지도 한 칸 색 회복(15칸), 사물함 물건 하나, 소장 비밀 파일 한 줄. 연속 기록이나 줄어드는 수치는 없습니다.
- **시연 모드:** 깃허브 Pages 주소가 아닌 곳(미리보기, 파일)에서는 로비에서 주차·요일을 고를 수 있고, 브리핑 끝에 「다음 날 저녁으로」 버튼이 있습니다.
